# Capturas para o guia

Esta pasta está reservada para os prints do [guia do aplicativo](../GUIA-DO-APLICATIVO.md).
Nenhuma captura de uma conta real foi incluída no esboço.

Use os nomes numerados sugeridos no guia. Prefira PNG, mantenha a tela legível
e use dimensões parecidas nas capturas. Uma legenda deve explicar o controle
destacado e a ação que o usuário pode realizar.

Antes de publicar, confira nomes, e-mails, dispositivos, notificações, tokens,
identificadores e dados particulares. Use demonstrações ou cubra os dados com
uma área opaca; não dependa só de desfoque. Não capture senhas ou tokens preenchidos.

Depois de a imagem existir e estar revisada, o marcador pode virar:

```markdown
![Aba Branco: controles de brilho e temperatura](imagens/04-branco.png)
```

O caminho do exemplo é relativo ao arquivo GUIA-DO-APLICATIVO.md.
As regras atuais ignoram imagens e a auditoria sinaliza arquivos de captura.
A inclusão futura exige uma revisão explícita dessas regras e dos prints,
mantendo o bloqueio dos demais arquivos pessoais.
